
# BAC Note calculé

The project is split by platform and purpose:

- [Windows client](./windows-client/README.md) — bilingual C# WPF x64 desktop application
- `android-bac-app/` — Android Studio project and Android release APK
- [Website](./website/README.md) — responsive browser version of the Android calculator
- [iPhone app](./ios-app/README.md) — build an unsigned IPA on GitHub Actions and sideload it with a free Apple ID
- `language-preview/` — bilingual preview builds and screenshots

Build and publish instructions for the Windows application are in
[windows-client/README.md](./windows-client/README.md).
